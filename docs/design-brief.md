## 依頼概要

**アプリ名：** AI Agent Portal  
**用途：** カンファレンスのライブデモ（登壇者が聴衆1,000名の前で操作する）  
**目的：** 「AIエージェントがログインユーザーの権限でしかデータを返せない」という概念を、画面を見るだけで直感的に理解させる  
**画面サイズ：** 1920×1080（外部モニター出力）  
**ブラウザ：** Chrome

---

## アプリの構造

ページは1画面のみ（ダッシュボード型）。ログイン画面とポータル画面の2状態。

---

## ① ログイン画面

シンプルなセンタリングレイアウト。

**要素：**

- アプリ名「AI Agent Portal」
- サブテキスト「社内ビジネスデータを、あなたの権限で」
- 「Microsoft アカウントでログイン」ボタン（Microsoftブランドカラー）
- 小さめのフッター：「Powered by Microsoft Foundry × CData Connect AI」

**ムード：** エンタープライズ感のある落ち着いたデザイン。派手にしない。

---

## ② ポータル画面（メイン）

### 全体レイアウト

横3カラム構成。縦は画面いっぱいに広げる（スクロールなし）。

```
┌──────────────────────────────────────────────────────────────────┐
│ HEADER（固定・高さ 64px）                                         │
├─────────────────┬────────────────────┬───────────────────────────┤
│                 │                    │                           │
│  チャット        │  データ             │  Inside the Agent         │
│  （左・幅25%）  │  （中央・幅45%）    │  （右・幅30%）            │
│                 │                    │                           │
│                 │                    │                           │
└─────────────────┴────────────────────┴───────────────────────────┘
```

---

### HEADER

**左：** アプリ名「AI Agent Portal」＋小さいアイコン  
**右：** ユーザーアバター（イニシャル）＋名前＋役職バッジ ＋ 「ユーザー切替」ドロップダウン ＋ ログアウト

**ユーザー切替ドロップダウンの中身：**

```
● 田中 一郎（営業担当）← 現在選択中
  山田 花子（営業マネージャー）
```

ユーザーごとに役職バッジの色を変える（例：営業担当＝青、マネージャー＝紫）

---

### 左パネル：チャット

一般的なチャット UI。

**上部：** パネルタイトル「エージェントに質問する」  
**中央：** メッセージ履歴（ユーザー発言は右寄せ、エージェント応答は左寄せ）  
**下部（固定）：**

- プリセットボタン（3つ、横並び、小さめ）
  - 「今月のパイプラインを見せて」
  - 「金額が大きい順に並べて」
  - 「クローズが近い商談を教えて」
- テキスト入力欄 ＋ 送信ボタン

エージェント応答中はタイプライター効果でテキストを表示。ローディング中はドットアニメーション。

---

### 中央パネル：データ表示

Salesforce から取得した商談データをテーブルで表示。

**上部：**

- 「商談一覧」タイトル
- フィルタバッジ（例：`👤 田中 一郎` `📅 今月`）← 適用中のフィルタ条件
- 件数（例：「8 件」）

**テーブルカラム：**

| 商談名 | ステージ | 金額 | 担当者 | クローズ予定 |
| ------ | -------- | ---- | ------ | ------------ |

- ステージは色付きバッジで表示（例：Prospecting＝グレー、Negotiation＝黄、Closed Won＝緑）
- 金額はカンマ区切りの円表示
- エージェント未応答時は空状態プレースホルダー「💬 エージェントに質問するとデータが表示されます」

**デモの核心として強調したいポイント：**  
田中（営業担当）でログインしているときは `👤 田中 一郎` のフィルタバッジが目立つ形で表示されること。山田（マネージャー）に切り替えるとバッジが消えてデータ件数が増える、という視覚的な変化が重要。

---

### 右パネル：Inside the Agent

**このパネルが最も重要。** 認証・認可フローをリアルタイムで可視化する。

#### パネルタイトル

「🔍 Inside the Agent」

#### フロー表示（5ステップ）

各ステップを縦に並べ、状態アイコンで進行を示す。

```
① Entra ID 認証         ✅
   田中 一郎
   ID Token 取得済み

② OBO トークン交換      ✅
   Foundry Access Token 発行

③ Foundry 処理          ✅
   RBAC: Foundry User 確認済み
   Tool Approval: 承認

④ CData OAuth           ⏳  ← 初回：コンセント待ち
   [コンセントを承認する →]     ← クリック可能なリンク

⑤ MCP ツール呼び出し    ✅
   Tool: queryData
   Filter: owner = '田中 一郎'
   234ms
```

**状態アイコンの定義：**

- `✅` 完了（緑）
- `⚙️` 処理中（アニメーション）
- `⏳` ユーザー操作待ち（黄・点滅）
- `❌` エラー（赤）
- `-` 未実行（グレー）

#### トークン凡例（パネル下部）

3色のバッジを横並びで表示：

```
■ Entra Token（黄）　■ CData Token（緑）　■ SF Token（ピンク）
```

各ステップの詳細テキストにトークン種別バッジをインライン表示する。

## インタラクションの重点

1. **ユーザー切替**：ヘッダーのドロップダウンで切り替えると、フィルタバッジとデータ件数が変わることが一目でわかること
2. **フローの進行**：プロンプト送信後、右パネルのステップが上から順にリアルタイムで更新されること（聴衆がプロセスを追える）
3. **初回コンセント**：④ が `⏳` で止まり、「コンセントを承認する」リンクが出現する瞬間が、デモの一つの山場

---

## デザインに含めてほしい成果物

1. ログイン画面（デスクトップ 1920×1080）
2. ポータル画面：田中ログイン・エージェント未応答状態
3. ポータル画面：田中ログイン・エージェント応答後（Inside the Agent フロー完了）
4. ポータル画面：④ CData OAuth コンセント待ち状態（⏳ 点滅）
5. ポータル画面：山田に切替後・同じプロンプトへの応答（データ件数が増えた状態）
