## 1. 今回の作業の目的

AI Dev Day 2026（2026年7月24日）セッションのライブデモ用アプリ「AI Agent Portal」を**ゼロから実装する**。
確定デザイン（`design_handoff/`）を **1920×1080 でピクセル忠実に再現**し、デモシナリオ（田中↔山田の権限差）が動作する状態を作る。

本デモの最終目標は **Foundry / CData Connect AI MCP への実接続**だが、初回実装では
**「モックモードで演出フローを完成させる」→「実接続に差し替える」** の順で段階的に進める。
初回実装のゴールラインは **モックモードでデモが一気通貫で動くこと**（実接続は後続タスクで結線）。

## 3. ユーザーストーリー

- **US-1（聴衆視点）**：異なるユーザーで同じ質問をしたとき、返るデータ（件数・フィルタ）が変わる様子を見て、「エージェントは権限を超えられない」を直感的に理解したい。
- **US-2（登壇者視点）**：ユーザーを30秒以内に切り替えて同じ質問を再送し、対比を見せたい（**チャット履歴は保持**）。
- **US-3（登壇者視点）**：④ CData OAuth が `⏳` で止まり、コンセント承認ボタンを押すと再開する「山場」を演出したい。
- **US-4（登壇者視点）**：会場ネットワークが不安定でも、モックモードで確実にデモを完遂したい。

## 4. 受け入れ条件

- [ ] ログイン画面 →（Microsoft ボタン押下）→ ポータル画面に遷移する
- [ ] プリセット「今月のパイプラインを見せて」送信で、田中の商談 **8件**（合計 ¥79,000,000）が Markdown テーブルで返る
- [ ] Inside the Agent が ①→⑤ の順にリアルタイム進行し、進行中セクションが最上部に自動スクロールする
- [ ] ④ CData OAuth が**初回のみ** `⏳`（待機）で停止し、コンセント承認ボタンが出現する
- [ ] コンセント承認後、④→⑤ が再開して完了する。2回目以降・ユーザー切替後は④で止まらない
- [ ] 山田に切替 → 同じプロンプト再送 → **16件**（フィルタなし）が返る。**チャット履歴は保持**される
- [ ] ⑤のフィルタ注記がユーザーに連動（田中 `owner = '田中 一郎'` / 山田 `全担当（マネージャー権限）`）
- [ ] `NEXT_PUBLIC_MOCK_MODE=true` でモックデータが表示される
- [ ] 1920×1080・Chrome 最新版で確定デザインが忠実に再現されている

## 5. 制約事項

| 制約 | 内容 |
|------|------|
| 解像度 | 1920×1080 固定。レスポンシブ不要 |
| ブラウザ | Chrome 最新版で動作保証 |
| フォント | Noto Sans JP（Google Fonts, 400/500/600/700） |
| デザイン忠実度 | High-fidelity。配色・余白・タイポ・アニメーションまで `design_handoff` に忠実 |
| セキュリティ | クライアントシークレットはサーバー側のみ。トークンは localStorage 不使用 |
| 状態の初期値 | screen=login / user=tanaka / requireConsent=true / stepDelay=9500ms |
| スケジュール | 7/22 リハーサル・7/24 本番に間に合わせる |
